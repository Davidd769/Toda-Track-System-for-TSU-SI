📖 How to Use the Student Side

1. View Waiting Trips

Check the "Waiting Trips" section to see all trips that are waiting for a tricycle assignment. Each card shows the destination, route, passenger count, and fare.

2. Monitor Active Trips

The "Active Trips" section displays all trips currently in progress. You can see which tricycle is assigned and track the trip status.

3. Check Available Tricycles

View all tricycles that are currently available and ready to accept new trips. The table shows driver names, plate numbers, and capacity.

4. Real-Time Updates

The page automatically refreshes every 3 seconds, so you always see the most up-to-date information without needing to manually refresh.

🔍 Understanding Trip Information

📍 Route & Destination

Shows the starting point and final destination of the trip. For example, "Gate 1 to Main Building" or "Dormitory to Library".

👥 Passenger Count

Indicates how many passengers are traveling. This helps determine which tricycle (based on capacity) can accept the trip.

💰 Fare

The cost of the trip in Philippine Peso (₱). Fares are displayed in the standard currency format with two decimal places.

🏷️ Trip Status

Waiting - Trip is waiting for tricycle assignment
Active - Trip is currently in progress
Completed - Trip has been finished
