📖 Driver Usage Guide

Learn how to effectively use the Driver Dashboard features

1️⃣ Register Your Tricycle

Start by registering your tricycle in the system. Fill out the registration form with your plate number (format: ABC-123), driver name, and passenger capacity. Once registered, your tricycle will appear in the system and be ready to accept trips. 

// Example registration
Plate Number: ABC-123
Driver Name: Juan Dela Cruz
Capacity: 4 passengers

2️⃣ Start a Trip

When you're ready to start a trip, select your tricycle from the dropdown menu and fill in the trip details (destination, route, passengers, fare). The system will automatically mark your tricycle as "on-trip" and track the journey.

Tip: Only available tricycles appear in the dropdown. If yours isn't listed, it may already be on a trip or off-duty.

3️⃣ Complete Trips

Once you've delivered your passengers to their destination, use the "Complete Trip" button in the Active Trips section. This will mark the trip as finished, update your tricycle status back to "available", and archive the trip for record-keeping.

After completing a trip, your tricycle becomes immediately available for new assignments.

4️⃣ Monitor Your Status

Keep an eye on the Dashboard Overview to see system-wide statistics. The "Registered Tricycles" table shows the status of all tricycles, including your own. Real-time updates ensure you always have the latest information.

The page auto-refreshes every 3 seconds to show real-time updates.

✅ Best Practices for Drivers

⚡ Quick Response

Accept trip requests as soon as possible to provide the best service to students. The faster you respond, the shorter their wait time.

📱 Stay Updated

Keep the dashboard open during your duty hours to receive real-time notifications about new trip requests and system updates.

✅ Complete Promptly

Mark trips as completed immediately after drop-off so your tricycle becomes available for the next passenger.

🔍 Double-Check Details

Always verify the destination, route, and passenger count before starting a trip to avoid confusion.

💻 Technical Implementation Examples

How Driver Registration Works

Behind the scenes, the registration process uses object-oriented programming:

// Step 1: Validate input data
if (!plateNumber || !driverName || !capacity) {
    return { success: false, message: 'All fields required' };
}

// Step 2: Check for duplicates
const exists = tricycles.find(t => t.plateNumber === plateNumber);
if (exists) {
    return { success: false, message: 'Already registered' };
}

// Step 3: Create new Tricycle object
const newTricycle = new Tricycle(plateNumber, driverName, capacity);

// Step 4: Add to database
tricycles.push(newTricycle);

// Step 5: Return success
return { success: true, tricycle: newTricycle };

How Trip Starting Works

The trip startup process ensures proper state management:

// Step 1: Create trip object
const trip = new Trip(id, destination, passengers, fare, route);

// Step 2: Find available tricycle
const tricycle = tricycles.find(t => 
    t.plateNumber === selectedPlate && 
    t.status === 'available'
);

// Step 3: Assign trip to tricycle
if (tricycle.startTrip(trip)) {
    trip.assignTricycle(tricycle);
    return { success: true };
}

// Tricycle.startTrip() method handles state validation
startTrip(trip) {
    if (this.status === 'available') {
        this.status = 'on-trip';
        this.currentTrip = trip;
        return true;
    }
    return false; // Prevents invalid state changes
}
